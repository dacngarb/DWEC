# 🌐 DWEC — Desarrollo Web en Entorno Cliente

Repositorio dedicado a la asignatura **Desarrollo Web en Entorno Cliente (DWEC)** del ciclo de **Desarrollo de Aplicaciones Web (DAW)**.

Aquí iré subiendo las prácticas, ejercicios y proyectos que vaya realizando durante el curso.

---

## 📚 Contenidos

### 🧱 HTML

Trabajo con la estructura y organización de páginas web.

* Estructura de documentos HTML
* Etiquetas y atributos
* Enlaces
* Imágenes
* Listas
* Tablas
* Formularios
* Elementos semánticos
* Organización de páginas

---

### 🎨 CSS

Diseño y presentación de las páginas web.

* Selectores
* Clases e identificadores
* Colores
* Tipografías
* Márgenes y padding
* Bordes
* Fondos
* Flexbox
* Posicionamiento
* Diseño responsive

---

### ⚡ JavaScript

Programación e interacción con las páginas web.

* Variables
* Tipos de datos
* Operadores
* Condicionales
* Bucles
* Funciones
* Arrays
* Objetos
* Eventos
* DOM
* Manipulación de elementos HTML
* Formularios
* Validaciones
