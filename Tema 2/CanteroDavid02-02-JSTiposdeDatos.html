6. ¿Cómo se referencia un archivo .js en HTML?

7. ¿Qué debe hacer si el archivo JavaScript se encuentra en otro directorio?

Deberá especificar la ruta completa o relativa al archivo JavaScript en el atributo "src" de la etiqueta "script"

8. ¿Qué etiqueta se usa para mostrar un mensaje si el navegador no soporta JavaScript?

9. ¿Qué diferencia hay al insertar JavaScript en XHTML?

En XHTML, los elementos deben estar bien cerrados y los atributos deben estar entre comillas

10. ¿Qué es la ofuscación de código y por qué se utiliza?

La ofuscación de código es una técnica que consiste en dificultar la lectura y comprensión del código fuente, con el fin de proteger la propiedad intelectual o evitar que otros lo manipulen fácilmente

13. ¿Por qué Microsoft usó el nombre Jscript?

Porque JavaScript era una marca registrada de Sun Microsystems, así que Microsoft no podía usar ese nombre y lo llamó JScript

es la representación de un documento HTML en forma de árbol de elementos. Fue diseñado para que los programas, como JavaScript, pudieran acceder y modificar el contenido, estructura y estilo de una página web
